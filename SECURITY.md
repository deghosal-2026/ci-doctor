# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via:

- **Preferred:** [GitHub's private vulnerability reporting](https://github.com/deghosal-2026/ci-doctor/security/advisories/new)
- **Alternative:** Email **deghosal@gmail.com**

Do **not** open a public issue. You can expect an initial response within 48 hours.

## Supported Versions

Only the latest release is actively supported.

## Scope

This policy covers the entire repository.
